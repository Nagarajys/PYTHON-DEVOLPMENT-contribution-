# AI Dataset Quality Analyzer

A Python-based project designed to analyze
CSV datasets and identify data quality issues.

## Features

- Load CSV datasets
- Detect missing values
- Identify duplicate records
- Calculate numerical statistics
- Validate dataset columns
- Generate quality reports
- Handle file errors

## Technologies Used

- Python
- CSV Module
- Exception Handling
- File Handling
- Unit Testing
